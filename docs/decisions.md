# Design decisions

## 25 October 2026

1. **Start with prevention and evidence.** The initial executable scope is a
   deterministic acceptance-review core and a fictional procedural simulator.
   A legally operative agent court requires substantially more institutional work.
2. **Keep Piepowder standalone.** Symbolon remains responsible for its transaction
   workflow and TEST ledger. A read-only review export is the next integration target.
3. **Use Python first.** Standard-library code makes the first workflow reproducible
   without a server, API credentials, external models, paid infrastructure or a
   second language. Add a service boundary only when an observed integration needs it.
4. **Preserve ambiguity.** An unspecified denominator produces two readings and a
   human-review finding. It does not insert a default interpretation or choose a winner.
5. **Keep trust dimensions separate.** Byte equality, recorded authority limits,
   identity, signatures, time, factual truth and legal effect remain different fields.
6. **Treat procedural timeout as a review event.** Late responses remain recordable;
   a timeout creates no acceptance, damages, refund, award or payment instruction.
7. **Keep the project private.** The working name, public licence, release audience,
   security reporting and disclosure review remain open decisions. The report's
   suggested open licences are not automatically granted.
8. **Retain the source and corrections separately.** Preserve the uploaded report
   unchanged and record legal, protocol, mathematical and market corrections with
   sources. A working implementation does not validate every founding claim.
9. **Continue within the existing development routine.** Preserve the shared
   one-active-improvement limit and all existing schedules and paused tasks.
10. **Measure use before expanding.** Unit tests establish bounded implementation
    behaviour. Independent reviewer usefulness, paid demand and repeat orders need
    their own evidence and must not be inferred from the number of tests or files.
